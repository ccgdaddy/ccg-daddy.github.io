# CCGs Unblocked Games

Free static game-site starter.

## Run it
Open `index.html` in a browser.

## Add a game
1. Put the game's web files inside `games/<game-name>/`.
2. Make sure the game's main page is `index.html`.
3. Add an entry to `games.js`.
4. Open the site again.

## Publish free
Upload the folder to a GitHub repository and enable GitHub Pages in the repository's Pages settings.

Only host games you own, have permission to redistribute, or that are licensed for redistribution.
